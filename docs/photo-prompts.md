# Product photo prompts

One prompt per photo in `client/public/products/`. Generate each one, save it under the
**file name shown**, and drop it in that folder (any format — it gets converted and the
white background removed).

Tips
- Keep every prompt's wording unchanged apart from the garment line, so the rail looks like one shoot.
- Reject any result showing a mannequin neck, hanger, hook, tag, or a cropped hem/sleeve.
- Colour variants of the same product: generate them in the same session, and if your tool
  supports it, attach the first approved image as a reference ("same garment, recolored").
